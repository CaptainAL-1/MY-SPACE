# My Space
Personal site for code, life thoughts, recipes, science facts and hackathon projects.

## Put it online (GitHub Pages, free)
1. Create a repository on github.com (public).
2. Upload all files from this folder (index.html, data/posts.json, .nojekyll, README.md).
3. Repo Settings > Pages > Source: "Deploy from a branch", Branch: main, folder: / (root), Save.
4. Your site appears at https://YOURNAME.github.io/REPONAME/ after about a minute.

## Add posts from the website
1. GitHub > Settings > Developer settings > Personal access tokens > Fine-grained tokens > Generate new token.
2. Repository access: Only select repositories > pick this repo. Permissions > Contents: Read and write.
3. Open your site, click "Owner login" at the bottom, paste the token. Only you have it.
Posts are saved into data/posts.json in your repo.
